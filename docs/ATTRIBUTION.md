# Dataset, model and software attribution

- **MAESTRO v3.0.0:** the official MIDI dataset distributed by the Magenta project. [Official dataset page](https://magenta.withgoogle.com/datasets/maestro) and [official MIDI archive](https://storage.googleapis.com/magentadata/datasets/maestro/v3.0.0/maestro-v3.0.0-midi.zip). The frozen archive is 58,416,533 bytes; SHA256 `70470ee253295c8d2c71e6d9d4a815189e35c89624b76d22fce5a019d5dde12c`. The source's retained dataset notice is Attribution-NonCommercial-ShareAlike 4.0 International. Dataset binaries are not included.
- **MERT-v1-95M:** Multimodal Art Projection (m-a-p), [official model card](https://huggingface.co/m-a-p/MERT-v1-95M). Yizhi Li and colleagues, *MERT: Acoustic Music Understanding Model with Large-Scale Self-supervised Training*, ICLR 2024 ([paper](https://proceedings.iclr.cc/paper_files/paper/2024/hash/33dffa2e3d2ab74a783d1a8c292f66d9-Abstract-Conference.html)). Identity, revision and file hashes are in the [model manifest](../results/model_manifest.json); model weights are not included.
- **FluidSynth and TimGM6mb:** the study uses FluidSynth 2.4.4 and the pinned TimGM6mb SoundFont. The retained source notice identifies TimGM6mb as GPL-2. Neither binary is redistributed; the SoundFont hash is recorded in [methods](METHODS.md).
